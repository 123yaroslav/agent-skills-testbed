# Как вносить изменения

```bash
uv sync
uv run pre-commit install
```

- Домашнее задание N делаем в ветке `hw_N` и вливаем в `main` через PR после ревью ментора, двух студентов и зеленого CI.
- Остальное делаем в ветках `feat/...`, `fix/...`, `docs/...`.
- Один коммит, одно изменение. Сообщение в повелительном наклонении, например `Add pass^k estimator`.
- Если хук упал, исправьте файл и повторите коммит. `--no-verify` не используем, CI такой коммит все равно не пропустит.
- Ключи API храним только в `.env`. Если ключ попал в историю, сразу отзовите его у провайдера.
- Зависимости добавляем через `uv add` и коммитим `uv.lock`.
