# Как вносить изменения

## Окружение

Нужны Python 3.12 и [uv](https://docs.astral.sh/uv/).

```bash
uv sync                    # зависимости из uv.lock
uv run pre-commit install  # хуки перед каждым коммитом
```

## Ветки и PR

- Домашнее задание N делаем в ветке `hw_N` от `main`.
- PR из `hw_N` в `main`. В ревьюеры добавляем ментора и двух студентов-ревьюеров.
- Вливаем после одобрения ревьюеров и зеленого CI.
- Остальные изменения делаем в ветках `feat/...`, `fix/...`, `docs/...`.
- Одно логическое изменение в одном коммите. Сообщение короткое и в повелительном наклонении, например `Add pass^k estimator`.

## Проверки

| Команда | Что делает |
|---|---|
| `uv run ruff check --fix .` | линтер, исправляет что может |
| `uv run ruff format .` | форматирует код |
| `uv run mypy` | проверяет типы в строгом режиме |
| `uv run pytest` | запускает тесты |
| `uv run pre-commit run --all-files` | все хуки разом, так же как в CI |

Хуки описаны в `.pre-commit-config.yaml`, настройки ruff, mypy и pytest лежат в `pyproject.toml`. Если хук упал, исправьте файл, добавьте его в индекс и повторите коммит. Коммит с `--no-verify` не делаем, CI все равно его не пропустит.

## Секреты

Ключи API храним только в `.env`, он в `.gitignore`. Хук gitleaks блокирует коммит с ключом. Если ключ все же попал в историю, сразу отзовите его у провайдера. Переписать историю недостаточно.

## Зависимости

Добавляем через `uv add <пакет>` или `uv add --dev <пакет>` и коммитим обновленный `uv.lock`.
